# QA-Task (Persian RAG / QA)

## Summary
This repository contains code and data for a Persian QA / RAG evaluation (Tasks A, B, and C as described in [Task.pdf](Task.pdf)).  
The dataset `qadata/drugs_aq_dataset.json` was generated by ChatGPT for RAG evaluation; its text and answer spans were extracted from [qadata/Drugs.pdf](qadata/Drugs.pdf).

The pipeline has been **enhanced** with:
- Advanced PDF → Markdown conversion using **Marker-PDF**
- **Five chunking strategies** (word, sentence, semantic, hierarchical, markdown)
- **Four retrieval methods** (BM25, TF-IDF, Embedding, Hybrid)
- **Fine-tuning** for embedding and QA models
- Expanded **evaluation metrics** (F1, EM, CosSim, MRR, Hit@K, Precision, Recall)

## Important Functions (see [task2_refined.py](task2_refined.py))

### Document & Preprocessing
- `extract_document_text` — enhanced PDF/Markdown text extraction (Marker-PDF + fallback).
- `extract_document_with_blocks` — block-level PDF parsing (headings, lists, forms, tables).
- `normalize_persian` — Persian text normalization helper.
- `map_to_squad` — maps dataset entries to SQuAD-like format.

### Chunking
- `word_based_chunk` — word-based chunking.
- `sentence_based_chunk` — sentence-based chunking.
- `semantic_based_chunk` — embedding similarity–driven chunking.
- `hierarchical_chunk` — recursive splitting with separators.
- `markdown_chunk_with_blocks` — block-aware chunking using Marker-PDF.

### Retrieval & QA
- `build_bm25` / `build_tfidf` / `build_embedding_index` — build retrieval indexes.
- `retrieve_bm25`, `retrieve_tfidf`, `retrieve_embedding`, `hybrid_retrieve` — retrieval functions.
- `rag_pipeline` — end-to-end RAG retrieval + QA.
- `answer_question` — QA wrapper with best-answer selection.

### Evaluation
- `comprehensive_evaluation` — runs retrieval + QA evaluation across methods.
- Metrics: F1, EM, Cosine Similarity, MRR, Precision, Recall, Hit@K.
- `find_best_method` — ranks chunking/retrieval combinations.
- `save_results` — saves metrics and best method to JSON.

   ```bash

   ```python task2_refined.py  ```

Run QA pipeline and evaluation.
